# Topic Tracker for YouTube

The public site for the **Topic Tracker for YouTube** Chrome extension: a
landing page and the privacy policy.

Published with GitHub Pages:

- <https://LunguRadu.github.io/topic-tracker-for-youtube/>
- <https://LunguRadu.github.io/topic-tracker-for-youtube/privacy.html>

The privacy policy URL is what the Chrome Web Store listing points at, so it
needs to stay reachable for as long as the extension is published.

This repository holds the site only. The extension's source lives in a separate
private repository.

## Editing

Two static HTML files, no build step and no dependencies. Edit and push; Pages
redeploys on its own.

Both files carry their own styles inline and adapt to the reader's light or dark
theme.
